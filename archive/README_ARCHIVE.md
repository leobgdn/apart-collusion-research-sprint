the repository was reorganised into `pricing/` (Track A) and `colosseum/`
(Track B). It contains Plan B Stage 1 (pricing environment, scripted controls,
tests) and the Plan A adapter for Colosseum on Fireworks-hosted Qwen3-8B, which
was never run.

Nothing here is used by either track. `pricing/` started from this code (commit
`68c2f46`) and supersedes it; see `pricing/DECISIONS.md`. Git history for these
files is preserved (the move was a `git mv`).
